ตั้งสิทธิ์ของร้าน

เจ้าของร้านอยากตั้งเองว่าใครเห็นตัวเลขเงินอะไร และใครทำอะไรได้ โดยไม่ต้องเริ่มจากศูนย์ คิดครัวตั้งค่าเริ่มต้นให้ทุกบทบาท ร้านปรับเฉพาะข้อที่ร้านตัวเองต่างไป แล้วยกเว้นให้รายคนได้

ระบบอื่นทำอย่างไร

Toastสองชั้นแบบเดียวกับ ADR 0038: สิทธิ์ตาม “งาน” (job) เป็นค่าเริ่มต้น แล้ว override รายคนได้ ช่องที่ได้จากงานเป็นสีเทา ช่องที่ยกเว้นรายคนเป็นสีน้ำเงิน คนที่จะแก้สิทธิ์ของใครต้องมีสิทธิ์ทุกข้อของคนนั้นอยู่แล้วเราใช้: แยกสี “ตามบทบาท” กับ “ยกเว้น” และกฎให้ได้ไม่เกินที่ตัวเองมี (ADR 0029 ข้อ 1)
Square for Restaurantsชุดสิทธิ์ (permission set) ทุกคนในชุดได้เท่ากันหมด เริ่มจากระดับสำเร็จรูป มาตรฐาน / เพิ่ม / เต็ม แล้วติ๊กปรับ มีตารางตัวอย่างบทบาทร้านอาหาร (แคชเชียร์ เสิร์ฟ บาร์) ให้เป็นจุดเริ่มเราใช้: ค่าเริ่มต้นพร้อมใช้ และคำอธิบายบทบาทใต้ชื่อ
Lightspeed Restaurantกลุ่มผู้ใช้ (Manager, Chef, Cook…) เป็นชุดสิทธิ์สำเร็จรูป ตอนเพิ่มคนเลือกได้ว่าจะเข้ากลุ่ม หรือปรับสิทธิ์ทีละข้อเองยืนยันว่าเจ้าของร้านคิดเป็น “บทบาทก่อน รายคนทีหลัง”
Restaurant365บทบาทของระบบแก้ไม่ได้และลบไม่ได้ ต้องคัดลอกเป็นบทบาทใหม่ก่อนจึงปรับได้ คนจัดการผู้ใช้แก้ได้แค่ในระดับสิทธิ์ของตัวเอง มีบันทึกเหตุการณ์ว่าใครเปลี่ยนอะไรเราเลือกต่าง: ปรับบทบาทเดิมได้เลย เก็บแค่ส่วนต่าง จึงกลับเป็นค่าเริ่มต้นได้เสมอ (ADR 0038 Q3)
Zoho Inventoryซ่อนราคาซื้อจากบทบาทไหนไม่ได้ ถ้าบทบาทนั้นยังเข้าหน้าซื้อของได้อยู่ปัญหาเดียวกับ ADR 0038 Q2: หน้าที่มีราคาในตัวต้องมาคู่กับ “เห็นต้นทุน”
MarketManไม่พบเอกสารสาธารณะเรื่องหน้าตั้งสิทธิ์ จึงไม่ได้ใช้เป็นแบบถ้าต้องการ ต้องขอดูจากบัญชีทดลองใช้

เจ้าของร้านถามอะไรเวลาตั้งสิทธิ์

คำถามใครถาม · บ่อยแค่ไหนหน้าจอตอบด้วยมีวันนี้ไหม
ผู้จัดการสาขาควรเห็นกำไรไหมเจ้าของ · ตอนเปิดร้าน ตอนเปลี่ยนผู้จัดการตาราง ช่อง “เห็นต้นทุนและกำไร” × ผู้จัดการยังไม่มี ล็อกในโค้ด
แคชเชียร์เห็นยอดขายทั้งวันได้ไหมเจ้าของ · ครั้งเดียวช่อง “เห็นยอดขาย” × แคชเชียร์ยังไม่มี
ใครกดส่งใบสั่งซื้อจริงได้เจ้าของ ผู้จัดการ · ครั้งเดียวช่อง “ส่ง/ยกเลิกใบสั่งซื้อ”ยังไม่มี
คนรับของต้องเห็นราคาไหมเจ้าของ · ตอนตั้งคนรับของติ๊ก “รับของ” แล้วระบบเปิด “เห็นต้นทุน” ให้พร้อมเหตุผลยังไม่มี วันนี้ทุกคนที่รับของได้บังเอิญเห็นราคาอยู่แล้ว
คนนี้คนเดียว ขอให้ทำได้มากกว่าเพื่อนในบทบาทเดียวกันผู้จัดการ · เป็นครั้งคราวแผงสมาชิก: เปิด/ปิดรายข้อยังไม่มี ต้องเปลี่ยนบทบาททั้งก้อน
ตอนนี้ใครเห็นต้นทุนบ้างเจ้าของ · ตอนมีคนลาออกแถบสรุปเหนือรายชื่อ กดแล้วกรองคนบางส่วน ต้องจำว่าบทบาทไหนเห็น
สิทธิ์จริงของคนนี้คืออะไรผู้จัดการ · ตอนมีคนบอกว่า “เข้าหน้านี้ไม่ได้”กล่อง “สิทธิ์จริงของคนนี้” บนแผงสมาชิกบางส่วน ดูได้แค่คำอธิบายบทบาท
ใครไปเปลี่ยนสิทธิ์ เมื่อไหร่เจ้าของ · ตอนมีอะไรแปลกแท็บบันทึกการเปลี่ยนบางส่วน มีแค่ “แก้ไขล่าสุดโดย” ต่อคน
ปรับจนงงแล้ว กลับค่าเดิมได้ไหมเจ้าของ · นาน ๆ ครั้งปุ่ม “กลับเป็นค่าเริ่มต้น” ต่อบทบาทยังไม่มี

สิ่งที่ตัดสินแล้ว (ADR 0038) และหน้าจอนี้ทำตาม

  1. สิทธิ์จริง = ของบทบาท (ตามที่ร้านปรับ) + ที่เปิดให้คนนั้น − ที่ปิดให้คนนั้น · ฐานข้อมูลเก็บเฉพาะส่วนที่ต่างจากค่าเริ่มต้น สิทธิ์ใหม่ที่ออกภายหลังได้ค่าเริ่มต้นเอง
  2. ตารางบทบาท: เจ้าของร้านเท่านั้น · ข้อยกเว้นรายคน: คนที่จัดการสมาชิกได้ แต่ให้ได้ไม่เกินสิทธิ์จริงของตัวเอง
  3. เชิญคน/แก้คนในร้าน และตั้งค่าร้าน ปรับไม่ได้ · ถ้าปรับได้ ใครก็ยกสิทธิ์ตัวเองกลับมาได้
  4. สิทธิ์ที่เห็นเงินในตัวมาคู่กับ “เห็นต้นทุน” · ติ๊กแล้วเปิดให้พร้อมบอกเหตุผล เอา “เห็นต้นทุน” ออกต้องเอาข้อที่พึ่งมันออกด้วย
  5. ทุกการเปลี่ยนมีบันทึก · ใคร เปลี่ยนอะไร ของใคร/บทบาทไหน เมื่อไหร่
  6. มีผลทันที · ระบบตรวจสิทธิ์ทุกครั้งที่เปิดหน้า คนนั้นไม่ต้องออกแล้วเข้าใหม่ (ต่างจาก Toast ที่ต้องล็อกอินใหม่)

คำถามที่อยากให้คุณ Kong ตัดสิน

1. ปรับได้ 16 ข้อ มากไปไหมADR ประมาณไว้ 10–12 ข้อ ผมนับข้อที่ร้านต่างกันจริงได้ 16 ข้อ ส่วนข้อพื้นฐานอย่าง ขอซื้อของ นับสต๊อก บันทึกมื้อตัวเอง ร่างสูตร ไม่อยู่ในตาราง เพราะทุกบทบาทที่ทำงานครัวต้องมีผมแนะนำ: เก็บ 16 ข้อ จัดเป็น 4 กลุ่ม อ่านง่ายกว่าตัดเหลือ 12 แล้วร้านหาข้อที่ต้องการไม่เจอ
2. ผู้ดูแลส่วนกลางปรับได้ไหมวันนี้ผู้ดูแลส่วนกลางมีสิทธิ์เท่าเจ้าของ (ADR 0029 บังคับไว้ เพราะต้องสร้างผู้จัดการได้)ผมแนะนำ: ล็อกคอลัมน์ไว้เหมือนเจ้าของ ถ้าจะลดสิทธิ์ใครคนหนึ่ง ใช้ข้อยกเว้นรายคน
3. บันทึกค่าใช้จ่าย ต้องมาคู่กับ เห็นค่าใช้จ่าย ไหมหน้ารายการค่าใช้จ่ายแสดงยอดเงินทุกใบ คนที่บันทึกได้จะเห็นค่าเช่า ค่าไฟไปด้วยผมแนะนำ: ใช่ เป็นคู่สิทธิ์อีกคู่ (ยืนยันอีกครั้งตอน audit ขั้นที่ 2)

หลังคุณ Kong อนุมัติ

  1. Audit ทุกหน้าที่แสดงราคาโดยไม่เช็กสิทธิ์ “เห็นต้นทุน” (ใบสั่งซื้อ ใบรับของ แคตตาล็อกผู้ขาย หน้าตัดรอบ และที่เจอเพิ่ม) แล้วทำตารางคู่สิทธิ์ในโค้ด + เทสต์ที่แดงเมื่อหน้าใหม่แสดงราคาโดยไม่อยู่ในตาราง
  2. 🛑 Migration (ขออนุมัติแยก): ตารางส่วนต่างของบทบาท ตารางส่วนต่างรายคน ตารางบันทึกการเปลี่ยน พร้อม RLS
  3. สิทธิ์จริงโหลดพร้อม membership ในคิวรีเดียว ทุกที่ที่ถามด้วยบทบาทล้วนเปลี่ยนเป็นถามสิทธิ์จริง
  4. หน้าจอจริงตาม mockup นี้ + เทสต์ + คู่มือ + ทะเบียนการตั้งค่า
