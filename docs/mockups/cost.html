ของเสีย (ทิ้ง) คือของที่มีคนบันทึกไว้ว่าทิ้ง พร้อมวันที่และสาเหตุ — คุยกับครัวเรื่องการสั่งและการเก็บรักษา · ส่วนต่าง/ปรับปรุง คือของที่หายไปโดยไม่มีใครบันทึก ไม่ว่าจะเจอตอนนับสต๊อกหรือปรับด้วยมือ — คุยกับผู้จัดการสาขาเรื่องการรับของ การคีย์ข้อมูล หรือของหาย

รายการปรับสต๊อกที่เคยเลือกเหตุผล “ของเสีย” ก่อนหน้านี้ จะอยู่ในช่องส่วนต่าง/ปรับปรุง เพราะไม่มีเอกสารของเสียกำกับ — ตั้งแต่นี้ไป ให้บันทึกที่หน้า ของเสีย

รายได้ มาจากไฟล์ยอดขายที่นำเข้า — สาขาที่ยังไม่มีไฟล์จะขึ้น “—” ซึ่งแปลว่า ยังวัดไม่ได้ ไม่ใช่ขายไม่ได้ · เป็นยอดหลังหักส่วนลด ไม่รวม VAT และไม่รวม Service charge

กำไรขั้นต้น = รายได้ − ต้นทุนของที่ขายไป ซึ่งไม่ใช่ช่อง “ต้นทุนวัตถุดิบ” ทางซ้าย … วิธีคิดเลือกได้ต่อร้านที่ ตั้งค่าร้าน — นับสต๊อก หรือ สูตรอาหาร …

บางสาขามีสต๊อกติดลบหรือของที่ยังไม่ทราบต้นทุน — ตัวเลขต้นทุนของสาขานั้นจะแม่นขึ้นเมื่อคีย์ใบรับของครบ

ลองเล่น (โหมด “ที่เสนอ”)

  1. 1ชิปสาขากดได้จริง · “ทุกสาขา” = แท่งคู่เทียบกัน · เลือกสาขาเดียว = ทั้งหน้าเป็นของสาขานั้น และอีกสาขาเป็นเส้นประจาง ๆ ไว้เทียบ
  2. 2การ์ดตัวเลขคือแท็บของกราฟ กดการ์ดแล้วกราฟเปลี่ยนเป็นตัวนั้น · ตัวเลขนับขึ้นเมื่อเปลี่ยนเดือน · มีแท่งเล็กย้อนหลังในการ์ด
  3. 3ชี้คอลัมน์เดือน = แถบไฮไลต์ + กล่องบอกทั้งสองสาขาพร้อมลูกศรเทียบเดือนก่อน + ชิปเดือนด้านบนสว่างตาม · กด = ทั้งหน้าเปลี่ยนเป็นเดือนนั้น
  4. 4ของหาย (กดการ์ด “ของหาย”) ไม่ใช่ค่าเฉลี่ยต่อวันแล้ว เป็นจุดของการนับสต๊อกแต่ละครั้งตามวันที่นับจริง ขนาดจุด = มูลค่า · ชี้ = เทียบการนับครั้งก่อน · กด = ป๊อปอัปรายการที่หายจากการนับครั้งนั้น · เดือนที่ไม่ได้นับเป็นลายเส้น
  5. 5ตารางเทียบสาขา ชี้แถวไหน กราฟด้านบนแสดงตัวชี้วัดนั้นทันที (การ์ดเรืองตาม) · กดแถว = เลือกตัวนั้น · ★ = สาขาที่ดีกว่า · ช่องว่างเป็นเงินนับขึ้น
  6. 6ของที่ต้องตามต่อ เทียบการนับครั้งนี้กับครั้งก่อน ป้าย ใหม่ / แย่ลง / ดีขึ้น / แก้แล้ว
