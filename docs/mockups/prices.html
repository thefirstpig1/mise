รอบ 2 ตามที่คุณ Kong สั่ง

  1. ชื่อหน้า “การผันผวนราคาวัตถุดิบ”
  2. ดูแบบ: ภาพรวม · หมวดหมู่ · แผนก · สินค้า + ช่วง: รายสัปดาห์ / รายเดือน — ทุกแบบเป็นกราฟเส้นแนวโน้มวางเทียบกัน · ชี้กราฟ = เห็นค่าทุกเส้นในช่วงนั้น · กดป้ายสีเพื่อซ่อน/แสดงเส้น · ชี้แถวในตาราง = เส้นนั้นเด่น · ดูแบบสินค้า พิมพ์ชื่อเพื่อเพิ่มเส้น (เริ่มที่ 5 ตัวที่ซื้อเป็นเงินมากสุด)
  3. ① เทียบกับช่วงอ้างอิง — เลือกฐานได้: สัปดาห์แรก / เดือน ส.ค. / ช่วงก่อนหน้า (แต่ละจุดเทียบจุดก่อน) · หมวด/แผนก/ภาพรวม = ดัชนีถ่วงตามยอดซื้อ ไม่ใช่ค่าเฉลี่ยธรรมดา
  4. ② เทียบกับราคาที่เมนูรับได้ — ราคาที่รับได้ = ราคาที่ทำให้ทุกเมนูที่ใช้วัตถุดิบนี้มีต้นทุนพอดีเป้า (ถ่วงตามจานที่ขาย) · เส้น 0% = พอดีเป้า · เหนือ 0 = แพงเกินกว่าที่ราคาเมนูรองรับ · “เกินงบต่อเดือน” = เงินที่วัตถุดิบนี้ทำให้ต้นทุนเมนูเกินเป้า · เป้าตั้งต่อเมนูได้ (ค่าเริ่มต้น = เป้าร้าน 35%) — ตารางล่างสุด
  5. ตัวอย่างจริง: กุ้งขาว ราคาแทบไม่ขยับ (+1.2%) แต่แพงเกินที่เมนูรับได้มาตลอด เพราะเมนูกุ้งต้นทุน 40–57% ของราคาขาย — โหมด ① มองไม่เห็นเลย

⚠ ลงหน้าจริงต้องเพิ่ม “เป้าต้นทุนต่อเมนู” ในฐานข้อมูล (คอลัมน์ใหม่ใน menu ต้องขออนุมัติ) — ตอนนี้ร้านมีแค่เป้ารวม 35% · ราคาที่รับได้คิดจากราคาขายและสูตรปัจจุบัน แบ่งส่วนเกินให้วัตถุดิบตามสัดส่วนต้นทุนในจาน (สมมติว่าทุกวัตถุดิบในจานต้องลดเท่ากัน) · เครื่องดื่มซื้อมาขายต่อ (เบียร์ โค้ก) ร้านส่วนใหญ่ตั้งเป้าสูงกว่าอาหาร ลองแก้เป้าในตารางล่างสุด
