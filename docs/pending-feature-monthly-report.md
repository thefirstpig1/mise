## แบ่งเป็น 3 ชั้น

### ชั้น 1 — รายงานสรุปรายเดือน (ไม่ใช้ AI)
หน้าเดียวต่อเดือน ต่อสาขาและทั้งร้าน เปิดดูในแอปและดาวน์โหลดเป็น PDF/รูปได้
- P&L เทียบเดือนก่อน **ต่อวันที่มีข้อมูล** (กฎ SI) และเทียบเป้าที่ร้านตั้ง
- **จุดสังเกตแบบกฎตายตัว (pattern)** — ระบบคิดเองทุกข้อ ทุกข้อชี้ไปหน้าที่ดูต่อได้ ตัวอย่าง:
  - ต้นทุนอาหาร / prime cost เกินเป้า และเกินเพราะวัตถุดิบตัวไหน
  - วัตถุดิบที่ราคาขึ้นเกิน 3% และทำให้จ่ายเพิ่มกี่บาท
  - ของหายเกินเป้า รายการที่หายมากที่สุด
  - เมนูที่ยอดขายต่อวันตกหรือขึ้นมากที่สุด
  - วันในสัปดาห์ที่ขายดี/แย่ผิดปกติ ยอดต่อหัว
  - ค่าใช้จ่ายประจำที่ยังไม่ลงบิล บิลซื้อวัตถุดิบน้อยผิดปกติ (กฎเดียวกับ flow เริ่มใช้งาน ข้อ F)
  - ตัวเลขที่ยังคิดไม่ได้ และขาดอะไร (กฎ PG1 — ไม่มีตัวเลขเดา)
- **ความยาก:** กลาง — ตัวเลขทุกตัวมีฟังก์ชันอยู่แล้ว ส่วนใหม่คือหน้ารายงาน + กฎจุดสังเกต (~1–2 Part)

### ชั้น 2 — สรุปเป็นภาษาคนด้วย AI (Feature A2 เดิม)
AI อ่านตัวเลขและจุดสังเกตจากชั้น 1 แล้วเล่าเป็นภาษาคน แยกมุมเจ้าของ / ครัว / จัดซื้อ
- **AI ไม่คำนวณเอง** (กฎ AI-2) ได้แค่ตัวเลขที่ระบบคิดแล้วพร้อมความครอบคลุม
- ต้องเพิ่ม dependency `@anthropic-ai/sdk` และ key → 🛑 ต้องขออนุมัติ
- ค่าใช้จ่ายต่ำมาก (เดือนละครั้งต่อสาขา) ดูตาราง cost model ใน `pending-features-ai.md`
- **ความยาก:** ต่ำ ถ้าชั้น 1 เสร็จแล้ว

### ชั้น 3 — ส่งออกข้อมูลให้ AI ของร้านเอง
ไฟล์ zip ต่อเดือน (หรือช่วงที่เลือก) ที่ร้านอัปโหลดให้ ChatGPT / Gemini / Claude ของตัวเองได้
- **ข้อมูลดิบ:** ยอดขายราย วัน×เมนู, รายการรับของและราคา, ค่าใช้จ่าย, ใบนับ, ของเสีย, โอน, ตัดสต๊อก
- **ตัวเลขที่ระบบพิมพ์ออกมา** (P&L, ต้นทุน, ของหาย) เพื่อให้เทียบได้
- **ไฟล์กฎการคำนวณ** ภาษาไทยธรรมดา + ข้อจำกัดที่รู้อยู่แล้ว + กฎการปัดเศษ — AI ข้างนอกจะได้ไม่อ่านผิด (เหตุผลข้อ 1 ของ A2)
- **prompt สองแบบ เปิดให้อ่านและแก้ได้ทั้งหมด:**
  - "หาจุดสังเกต" — สรุปเดือนนี้ หาสิ่งผิดปกติ ให้คำนวณด้วยโค้ด/สเปรดชีต ไม่ใช่คิดในหัว
  - "ตรวจสอบแบบจับผิด" — คำนวณทุกตัวเลขใหม่เองแล้วรายงานทุกจุดที่ไม่ตรง
- **นี่คือ feature เดียวกับ "ชุดตรวจสอบ" ที่จดไว้ 2026-09-29** — รวมเป็นฟีเจอร์เดียว ใช้ไฟล์ชุดเดียว ต่างกันแค่ prompt
- **กฎที่ห้ามละเมิด (Kong 2026-09-29):** ไฟล์ที่ส่งออกต้องไม่มีข้อความชี้นำ AI ให้เข้าข้างเรา ("ตัวเลขนี้ตรวจแล้ว", "เชื่อถือได้") ไม่มีคำสั่งแฝง — ข้อความแบบนั้นคือ prompt injection ใส่ลูกค้าเราเอง · ควรมีเทสต์ที่แดงเมื่อไฟล์มีข้อความลักษณะคำสั่ง
- **ไม่ส่งออกชื่อพนักงาน** (กฎ AI-5 / PDPA) — ใช้รหัสแทนชื่อ
- **ความยาก:** ต่ำ–กลาง — รูปแบบ zip ทำแล้วในสำรองจ่ายและไฟล์ปิดเดือน ส่วนที่ต้องคิดคือไฟล์กฎภาษาไทยและ prompt

## ความเสี่ยง

- **AI ข้างนอกอ่านผิด** → แนบกฎ ความครอบคลุม และข้อจำกัดไปในไฟล์เสมอ
- **ข้อมูลออกจากระบบ** → ร้านเป็นคนกดส่งออกเอง ขึ้นคำเตือนก่อนดาวน์โหลด และไม่มีชื่อคน
- **คำนวณใหม่แล้วต่างกันเป็นสตางค์** → เผยแพร่กฎการปัดเศษ และจดข้อจำกัดที่รู้ (เช่น PR3a) ไว้ก่อน
- **ไฟล์ใหญ่เกินที่ AI รับได้** → แยกไฟล์รายเดือน ร้านทั่วไปเดือนหนึ่งแค่หลักพันแถว
