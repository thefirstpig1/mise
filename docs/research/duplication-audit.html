B · ข้อมูลเดียวกัน แค่หน้าตาต่าง — เสนอตัดหรือรวม

B1แดชบอร์ด: กราฟ “จากยอดขายสู่กำไร”

แดชบอร์ด · การ์ด 5 ใบด้านบนแดชบอร์ด · จากยอดขายสู่กำไรแดชบอร์ด · เงินจากยอดขายไปอยู่ที่ไหน

ยอดขาย − ต้นทุนขาย − ค่าใช้จ่าย = กำไรสุทธิ แสดง 3 รอบในหน้าเดียว กราฟแท่ง “จากยอดขายสู่กำไร” มีแค่ 4 ตัวเลขเดียวกับการ์ด ไม่มีอะไรเพิ่ม · “เงินจากยอดขายไปอยู่ที่ไหน” มีของเพิ่ม (แยกค่าใช้จ่ายรายหมวด % ของยอดขาย) จึงเก็บ

เสนอ: ตัดกราฟ “จากยอดขายสู่กำไร”

B2แดชบอร์ด: ตารางสาขาท้ายหน้า

แดชบอร์ด · การ์ดด้านบนแดชบอร์ด · ตารางสาขา

ตาราง ยอดขาย/ต้นทุน/กำไร/ค่าใช้จ่าย/สุทธิ ต่อสาขา — ตอนนี้มีสาขาเดียวที่มียอดขาย ตารางจึงเป็นตัวเลขเดียวกับการ์ดเป๊ะ ๆ (อีกแถวเป็น “—”)

เสนอ: แสดงตารางเฉพาะเมื่อมีอย่างน้อย 2 สาขาที่มียอดขายในช่วงนั้น

B3หน้า “เมนูที่ยังไม่มีสูตร” (/menus/coverage)

จัดการเมนู · การ์ด “3 เมนูยังไม่มีสูตร · มีสูตรแล้ว 93%” + ตัวกรอง “ยังไม่มีสูตร 3”ทดลองเมนู · “ขายอยู่แต่ยังไม่มีสูตร 3 เมนู ฿3,741” + รายการพร้อมปุ่มร่างสูตรเมนูที่ยังไม่มีสูตร (หน้าแยก)

รายการเดียวกัน 3 เมนู ตัวเลขเดียวกัน (93% · ฿3,741) อยู่ 3 ที่ หน้าแยกมีแค่สวิตช์ 7/30/90 วันเพิ่ม · ที่ทดลองเมนูมีปุ่ม “+ ร่างสูตร” ซึ่งเป็นสิ่งที่ต้องทำต่อจริง ๆ

เสนอ: ตัดหน้า /menus/coverage (ลิงก์ที่ชี้ไปหน้านี้ให้ไปทดลองเมนูแทน)

B4ค่าใช้จ่าย: “รายจ่ายตามหมวด” ในหน้ารายการบิล

ค่าใช้จ่าย · รายจ่ายตามหมวดวิเคราะห์รายจ่าย · แยกตามหมวด (เจาะลงได้ + ผู้ขาย + รายวัน)

ข้อมูลเดียวกัน หน้าวิเคราะห์ทำได้มากกว่าทุกอย่าง หน้ารายการบิลควรเป็นที่บันทึกและหาบิล

เสนอ: ตัดออกจากหน้ารายการบิล เหลือลิงก์ “วิเคราะห์รายจ่าย ›”

B5หน้าต้นทุน: ป๊อปอัพ “นับสต๊อก วันที่ …” (รายการที่ไม่ตรง)

ต้นทุน · ป๊อปอัพการนับของหายไปไหน · การนับครั้งเดียวกัน

รายการวัตถุดิบที่นับไม่ตรง ตัวเลขเดียวกัน แต่หน้าของหายไปไหนมีป้ายสาเหตุ รายการตรวจ และแนวโน้มด้วย — ป๊อปอัพเป็นฉบับย่อที่ไม่ได้ช่วยตัดสินใจเพิ่ม

เสนอ: กดจุดการนับ/รายการ “ไม่ตรงกับระบบ” แล้วไปหน้าของหายไปไหนที่ครั้งนั้นเลย

B6รายการ “ยอดคงเหลือ” (/stock) กับ “สินค้า/วัตถุดิบ” (/products)

สต๊อกคงเหลือ · วัตถุดิบ / คงเหลือ / มูลค่า / เคลื่อนไหวล่าสุดสินค้า/วัตถุดิบ · คงเหลือ / ต้นทุน / ขั้นต่ำ / ใช้ในกี่สูตร + แผงข้าง

รายการวัตถุดิบเดียวกัน คงเหลือเดียวกัน สองหน้า หน้าสินค้ามีมากกว่า (ขั้นต่ำ เตือนแดงเหลือง แผงแก้ไข) ยกเว้น “มูลค่ารวมต่อรายการ” และ “เคลื่อนไหวล่าสุด” ที่หน้าสินค้ายังไม่มี

เสนอ: รวมเป็นหน้าเดียว — หน้าสต๊อกเหลือเป็นทางเข้า ปรับสต๊อก · ประวัติ · โอน (ตรงกับโน้ตเดิม “ย้ายปุ่มตัดสต๊อกเข้าหน้าสต๊อก”) · ข้อนี้ใหญ่ ต้องทำ mockup ก่อน

B7แผงวัตถุดิบในหน้าเมนู กับ แผงสินค้าในหน้าสินค้า

จัดการเมนู → สูตร → กดวัตถุดิบ (แผงวัตถุดิบ)สินค้า/วัตถุดิบ → กดแถว (แผงสินค้า)

สองแผงแสดงของชุดเดียวกัน (คงเหลือ ใช้ต่อวัน พอใช้อีกกี่วัน ราคา ซื้อล่าสุด ปุ่มขอซื้อ) หน้าตาต่างกัน คนจำสองแบบ

เสนอ: ใช้แผงสินค้าแผงเดียวทั้งสองที่

B8ประวัติราคาของสินค้า

แผงสินค้า · ประวัติราคาการผันผวนราคาวัตถุดิบ · ป๊อปอัพ (ราคาทุกใบ + เฉลี่ยรายเดือน + ราคาที่เมนูรับได้)

ราคาทุกใบของสินค้าตัวเดียวกัน วาดสองแบบ ป๊อปอัพใหม่บอกได้มากกว่า (เส้นเฉลี่ย ราคาที่รับได้)

เสนอ: แผงสินค้าใช้กราฟเดียวกับป๊อปอัพ (ไม่ใช่ตัด — รวมให้เหลือแบบเดียว)

B9ยอดปิดร้าน (ยอดที่ลูกค้าจ่าย) — ทางเข้าคีย์สองที่

แดชบอร์ด · ยอดที่ลูกค้าจ่ายรายวัน + “+ คีย์ยอดวันนี้”ยอดขาย · “คีย์แล้ว 0 จาก 26 วัน · กดแท่งเพื่อคีย์” + “ตรวจกับใบสรุปปิดร้าน”

ตัวเลขเดียวกัน กรอกได้สองที่ หน้าตาสองแบบ

เสนอ: คีย์ที่แดชบอร์ดที่เดียว (เป็นงานประจำวัน) · หน้ายอดขายเหลือแค่บรรทัดตรวจความครบ + ลิงก์

B10ของที่รอกดรับโอน

แดชบอร์ด · งานที่รออยู่สต๊อกคงเหลือ · แบนเนอร์ “มีของกำลังส่งมา…กดรับ”ตัวเลขบนเมนูซ้ายหน้าโอน

เรื่องเดียว เตือน 4 ที่ — ใครเปิดแดชบอร์ดแล้วไปหน้าสต๊อกจะเห็นซ้ำ

เสนอ: ตัดแบนเนอร์ในหน้าสต๊อก เหลือแดชบอร์ด + ตัวเลขเมนูซ้าย + หน้าโอน

C · ตัวเลขเรื่องเดียวกันที่บอกไม่ตรงกัน — ต้องแก้

C1ยอดขาย ก.ย. ต่อวัน: แดชบอร์ดกับหน้ายอดขายบอกคนละทาง

แดชบอร์ด: ฿20,513/วัน · ▲ 27.8% เทียบ ส.ค.ยอดขาย: ฿23,668/วัน · ▼ 6.6% ต่อวัน

แดชบอร์ดหารด้วยวันในเดือน (30) และเทียบยอดรวม (ก.ย. มีข้อมูล 26 วัน ส.ค. 19 วัน) → บอกว่า “ขายดีขึ้น 28%” ทั้งที่ขายต่อวันลดลง 6.6% · ขัดกับกฎ SI1 (เทียบต่อวันที่มีข้อมูล)

เสนอ: แดชบอร์ดใช้วิธีเดียวกับหน้ายอดขาย (ต่อวันที่มีข้อมูล) ทุกการ์ด

C2แดชบอร์ด ก.ย.: กำไรสุทธิ ▲169% อัตรากำไรสุทธิ 50%

แดชบอร์ด: ค่าใช้จ่าย ▼55% · กำไรสุทธิ ฿307,642ต้นทุน: “ยังไม่มีค่าแรง ก.ย.”

เงินเดือน ก.ย. ยังไม่ได้บันทึก ค่าใช้จ่ายจึงลดลงครึ่งหนึ่งและกำไรดูพุ่ง แต่แดชบอร์ดไม่เตือนเลย ขณะที่หน้าต้นทุนบอกชัดว่ายังไม่มีค่าแรง

เสนอ: แดชบอร์ดเตือนเมื่อเดือนนั้นยังไม่มีรายการประจำที่ถึงกำหนด (เงินเดือน ค่าเช่า) และไม่บอกว่า “ดีขึ้น” จนกว่าจะครบ

C3“ต้นทุน %” สามตัวที่ชื่อคล้ายกันแต่คิดต่างกัน

แดชบอร์ด/ต้นทุน: food cost 37.4% (ของที่ตัดสต๊อกจริง ราคา FIFO)จัดการเมนู: “ต้นทุนวัตถุดิบเทียบยอดขาย” (สูตร × ราคาวันนี้ × ยอดขาย 30 วัน)ยอดขาย/กำไร: ต้นทุนสูตร ณ ปลายช่วง

สามตัวควรต่างกันจริง (ตัวหนึ่งคือของที่ใช้ไป อีกตัวคือ “ถ้าทำตามสูตรวันนี้”) แต่ชื่อบนจอทำให้คนคิดว่าเป็นตัวเดียวกันแล้วเห็นว่าไม่ตรง

เสนอ: ไม่ตัด แต่ตั้งชื่อให้ต่าง เช่น “ต้นทุนของที่ใช้ไปจริง” กับ “ต้นทุนตามสูตร (ราคาวันนี้)” และบอกในวงเล็บ

A · ข้อมูลเดียวกัน ความลึกต่างกัน — เก็บไว้ทั้งหมด

A1ยอดขายรายวัน

แดชบอร์ด: เส้นต่อสาขา (ภาพรวม)ยอดขาย: แท่ง วันหยุด กดดูวัน คีย์ยอดปิด

A2เมนูขายดี

แดชบอร์ด: 10 อันดับยอดขาย: หมวด → เมนู · จาน/กำไร · menu engineeringจัดการเมนู: 30 วัน + ต้นทุนต่อจาน (ที่จัดการ ไม่ใช่ที่วิเคราะห์)

A3ค่าใช้จ่ายรายหมวด

แดชบอร์ด: เฉพาะค่าใช้จ่ายดำเนินงาน เป็น % ของยอดขายวิเคราะห์รายจ่าย: ทุกหมวด เจาะลงได้ ผู้ขาย รายวัน

A4ต้นทุนและกำไรขั้นต้น

แดชบอร์ด: รายเดือนต้นทุน: รายสัปดาห์ เป้า prime cost สิ่งที่ต้องจัดการต้นทุนตามแผนกตารางต้นทุนละเอียด

ตารางต้นทุนละเอียดซ้ำหน้าต้นทุนเกือบทุกคอลัมน์ ยกเว้น 3 อย่างที่มีที่นี่ที่เดียว: ซื้อเข้ามา · ค่าใช้จ่ายอื่น · จ่ายแพงกว่าที่ถูกสุด (เทียบราคาระหว่างสาขา) → เก็บไว้เป็นตารางลึก

A5ไม่ตรงกับระบบ

ต้นทุน: ตัวเลขรวม + แนวโน้มของหายไปไหน: ทีละรายการ สาเหตุ รายการตรวจใบนับ: ทีละบรรทัดที่นับ

A6ราคาวัตถุดิบที่ขึ้น

ต้นทุน: 3 รายการที่จ่ายเพิ่มมากสุดการผันผวนราคาวัตถุดิบ: ทุกรายการ แนวโน้ม ราคาที่เมนูรับได้

A7เงินในสต๊อก

ต้นทุน: รวม + ของค้างนานตารางต้นทุนละเอียด: ต่อสาขาสินค้า: ต่อรายการ

D · เจอระหว่างตรวจ (ไม่ใช่ความซ้ำ)
