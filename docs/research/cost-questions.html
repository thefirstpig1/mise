ต้นทุน: เจ้าของร้านอยากรู้อะไร

คำถามที่เจ้าของร้าน ผู้จัดการสาขา และหัวหน้าครัวถามเรื่องต้นทุนจริง ๆ ตัวเลขที่ใช้ตอบ เกณฑ์ที่วงการใช้ กราฟที่เหมาะ และระบบเรามีข้อมูลตอบได้แล้วหรือยัง — เพื่อออกแบบหน้าจากคำถาม ไม่ใช่จากข้อมูลที่เรามี

สิ่งที่เจอ

Prime costตัวเลขที่วงการดูมากที่สุด = (ต้นทุนวัตถุดิบ + ค่าแรง) ÷ ยอดขาย · เป้า 55–65% · ถ้าตัวนี้ดี ที่เหลือพอจ่ายค่าเช่าและมีกำไร
รายสัปดาห์ทุกแหล่งย้ำว่าดูต้นทุนทุกสัปดาห์ ไม่ใช่สิ้นเดือน · รอสิ้นเดือน = ปัญหาวิ่งไปแล้ว 3–4 สัปดาห์ · หน้าเราตอนนี้ดูได้แค่รายเดือน/30 วัน
28–35%ต้นทุนอาหารที่ถือว่าปกติของร้านนั่งทาน (ไทย 28–35%) · ค่าแรง ~25–35% · ค่าเช่า 15–18%
เงินซ่อนอยู่ใน “ส่วนต่าง”ต้นทุนจริง − ต้นทุนตามสูตร บอกของหาย ของทิ้ง ตักเกินสูตร · ส่วนต่าง 2–3% ถือว่าปกติ เกินนั้นต้องหาสาเหตุ
เทียบสาขาผู้จัดการเขตเริ่มจาก: สาขาไหนลากกำไรลง · สาขาไหนเป็นต้นแบบ · ต้องเทียบด้วย % ไม่ใช่ยอดรวม และต้องเจาะลงไปถึงตัวสินค้าได้
เริ่มที่จุดบอดเดียวอย่าทำ 12 แดชบอร์ดพร้อมกัน ทำหน้าที่ตอบ “จุดบอดใหญ่สุด” ให้ดีก่อน — สำหรับร้านเรา = เงินรั่วตรงไหน

ใครดู ดูบ่อยแค่ไหน

เจ้าของร้าน

  • ทุกสัปดาห์: prime cost · ต้นทุนอาหาร % · เงินสด
  • ทุกเดือน: กำไร · เทียบเดือนก่อน · สาขาไหนดี/แย่ · เงินจมในสต๊อก
  • อยากได้คำตอบ ไม่ใช่ตาราง: “ดีขึ้นหรือแย่ลง เพราะอะไร”

ผู้จัดการสาขา

  • ทุกวัน: ของที่รับเข้าตรงใบสั่งไหม · ของทิ้ง
  • ทุกสัปดาห์: ต้นทุนอาหาร % และส่วนต่างเป็นเงิน · ราคาที่ขึ้น · ของทิ้งตามเหตุผล · นับของแพง
  • อยากรู้ว่า “ต้องไปจัดการตัวไหนก่อน”

หัวหน้าครัว

  • ตัวไหนหายเยอะ · ทิ้งอะไรเพราะอะไร · ตักตรงสูตรไหม · ของค้างนาน

ผู้ดูแลหลายสาขา

  • ทุกสัปดาห์: สาขาเรียงตามต้นทุน % ค่าแรง % ส่วนต่าง · ช่องว่างระหว่างสาขาเป็นเงิน · แนวโน้มของแต่ละสาขา

คลังคำถามเรื่องต้นทุน · 12 ข้อ

เรียงตามความสำคัญที่แหล่งข้อมูลให้ · “ระบบเรา” = ตอนนี้มีข้อมูลตอบได้ไหม

#คำถามตัวเลขที่ตอบเกณฑ์ทั่วไปกราฟที่เหมาะใคร · บ่อยแค่ไหนระบบเราควรอยู่หน้า
1ร้านแข็งแรงไหม สัปดาห์นี้Prime cost % = (ต้นทุนของที่ขายไป + ค่าแรง) ÷ ยอดขาย55–65%เส้นรายสัปดาห์ + แถบเป้า · การ์ดตัวเลขใหญ่เจ้าของ สัปดาห์มีบางส่วน
ค่าแรงมีถ้าร้านบันทึกเงินเดือนในหมวด “ค่าแรง”		ต้นทุน (บนสุด) · แดชบอร์ด
2ต้นทุนอาหารเท่าไร เทียบเป้าต้นทุนอาหาร % = ต้นทุนของที่ขายไป ÷ ยอดขาย28–35%เส้น/แท่งรายสัปดาห์ + แถบเป้าเจ้าของผู้จัดการ สัปดาห์มี
ตัดสต๊อกไม่ครบ = “อย่างน้อย”		ต้นทุน
3ดีขึ้นหรือแย่ลงเทียบช่วงก่อน ต่อวัน (▲▼)—ลูกศร + แท่งเล็กย้อนหลังในการ์ดทุกคน · สัปดาห์มีทุกตัวเลขในหน้า
4เงินรั่วตรงไหนส่วนต่าง = ต้นทุนจริง − ต้นทุนตามสูตร (เป็นเงินและ % ของยอดขาย) · ของหายจากการนับ≤ 2–3% ของยอดขายแท่งแนวนอนเรียงตามเงิน (ตัวไหนหายมากสุด) · จุดของการนับแต่ละครั้งผู้จัดการครัว สัปดาห์มี
รู้เฉพาะวันที่นับ		ต้นทุน · ของหายไปไหน
5ทิ้งอะไร เพราะอะไรของทิ้งเป็นเงิน แยกเหตุผล/ตัวสินค้า—แท่งตามเหตุผล · ตัวที่ทิ้งบ่อยครัว สัปดาห์มีของเสีย · สรุปในต้นทุน
6วัตถุดิบตัวไหนขึ้นราคา กระทบเท่าไร% เปลี่ยน × ปริมาณที่ซื้อ = เงินที่เพิ่ม—รายการเรียงตามเงินที่กระทบ + แท่งเล็กราคาย้อนหลังเจ้าของจัดซื้อ สัปดาห์มีราคาวัตถุดิบขึ้นลง · สรุปในต้นทุน
7จ่ายแพงเกินไหมจ่ายแพงกว่าที่ถูกสุด · ราคารับ ≠ ใบสั่ง—รายการผู้ขาย/สินค้าที่แพงกว่าผู้จัดการ วัน/สัปดาห์มีบางส่วน
มีตัวเลขรวม ยังไม่เจาะรายตัว		ต้นทุน · รับสินค้า
8สาขาไหนดี สาขาไหนแย่ทุกตัวชี้วัดข้างบน ต่อสาขา เป็น % · ช่องว่างเป็นเงินเทียบกับสาขาที่ดีที่สุดตารางเทียบ + ★ · ลำดับสาขาเจ้าของหลายสาขา สัปดาห์มีต้นทุน
9เงินจมในสต๊อกเท่าไร อะไรค้างนานมูลค่าสต๊อก · วันที่ของพอใช้ · ของไม่เคลื่อนไหว—แท่งตามหมวด · รายการของค้างเจ้าของ เดือนมีบางส่วน
มูลค่ามี · ของค้างนานคิดจากอัตราใช้ได้		สต๊อก · สรุปในต้นทุน
10เมนูไหนกำไรดี ควรปรับราคากำไรต่อจาน × จำนวนขาย (Menu engineering)—กราฟกระจาย 4 ช่องเจ้าของ เดือนมียอดขาย
11วัตถุดิบขึ้นแล้ว เมนูไหนโดนเมนูที่ใช้วัตถุดิบนั้น · ต้นทุน % ใหม่—รายการเมนูพร้อม % เดิม → ใหม่เจ้าของ เมื่อราคาเปลี่ยนมีบางส่วน
มีที่แผงวัตถุดิบ ยังไม่รวบรวม		ราคาวัตถุดิบขึ้นลง
12ตัวเลขเชื่อได้ไหมนับสต๊อกล่าสุดเมื่อไร · ตัดสต๊อกครบกี่วัน · ยอดขายครบทุกสาขาไหมนับอย่างน้อยเดือนละครั้ง (ของแพงทุกสัปดาห์)รายการตรวจสั้น ๆ ข้างตัวเลขทุกคนมีทุกหน้าที่มีตัวเลข
—เทียบงบที่ตั้งไว้จริง vs งบ—แท่งจริงข้างแท่งงบเจ้าของ เดือนไม่มี
มีแค่เป้า % ถ้าทำเป็นค่าที่ร้านตั้ง		— (ยังไม่ทำ)

หน้าต้นทุนควรเรียงแบบนี้

เรียงตามคำถาม ไม่ใช่ตามตาราง · แต่ละส่วนตอบหนึ่งคำถามและบอกว่าต้องทำอะไรต่อ

1การ์ด 4 ใบ (เป็นแท็บของกราฟ): Prime cost % · ต้นทุนอาหาร % · ส่วนต่าง/ของหาย % · ทิ้ง — ทุกใบเทียบเป้าและเทียบช่วงก่อน (ข้อ 1–3)
2กราฟแนวโน้ม รายสัปดาห์เป็นค่าเริ่มต้น (สลับรายเดือนได้) · แถบเป้า · แยกสาขา · ชี้/กดได้ (ข้อ 1–3)
3“ต้องจัดการก่อน” 3–5 เรื่องที่เป็นเงินมากที่สุดสัปดาห์นี้ รวมจากหลายแหล่ง: ของหายตัวใหญ่ · วัตถุดิบขึ้นราคา · จ่ายแพงเกิน · ทิ้งเยอะ — แต่ละเรื่องกดไปหน้าที่แก้ได้ (ข้อ 4–7)
4เทียบสาขา ตารางทีละตัวชี้วัด + ช่องว่างเป็นเงิน (ข้อ 8)
5เงินจมในสต๊อก + ของค้างนาน (ข้อ 9)
6ตัวเลขเชื่อได้แค่ไหน แถบเล็ก: นับล่าสุด · ตัดสต๊อกครบ · ยอดขายครบ (ข้อ 12)

ต้องตัดสิน / ต้องเพิ่มจากที่มี

  • ดูรายสัปดาห์: ตอนนี้ระบบคิดต้นทุนเป็นช่วงวัน ทำรายสัปดาห์ได้โดยไม่ต้องเพิ่มตาราง แต่ต้องวัดความเร็ว (คิดหลายช่วงย้อนหลัง)
  • Prime cost: ต้องให้ร้านบันทึกเงินเดือนในหมวด “ค่าแรง” · ถ้ายังไม่มีข้อมูล ต้องขึ้นว่า “ยังไม่มีค่าแรง” ไม่ใช่ 0
  • เป้า % เป็นค่าที่ร้านตั้งเอง: ต้นทุนอาหาร · prime cost · ส่วนต่าง — ค่าเริ่มต้นตามตารางข้างบน (ลงทะเบียนค่าที่ร้านตั้งได้)
  • “ต้องจัดการก่อน” รวมหลายแหล่งเป็นรายการเดียว จัดลำดับด้วย “เงิน” ตัวเดียว

หลักการสำหรับทุกหน้าในคิดครัว

  1. เริ่มจากคำถาม ไม่ใช่ข้อมูล: ก่อนออกแบบหน้า ค้นหาว่าคนที่ใช้หน้านั้น (เจ้าของ / ผู้จัดการ / ครัว / จัดซื้อ) ถามอะไร บ่อยแค่ไหน ใช้ตัวเลขอะไรตอบ เกณฑ์เท่าไร
  2. ทำคลังคำถามของหน้านั้น: คำถาม → ตัวเลข → เกณฑ์ → กราฟ → ความถี่ → ระบบมีข้อมูลไหม (แบบตารางข้างบน)
  3. เรียงหน้าตามคำถามสำคัญที่สุดก่อน และทุกส่วนต้องบอก “ทำอะไรต่อ” (ลิงก์ไปหน้าที่แก้ได้)
  4. ทุกตัวเลขบอกว่าเทียบกับอะไร และเชื่อได้แค่ไหน (เป้า · ช่วงก่อน · สาขาอื่น · ความครอบคลุม)
  5. คำถามไหนระบบยังตอบไม่ได้ บอกตรง ๆ และบอกว่าต้องทำอะไรถึงจะได้คำตอบ

หน้าที่จะทำแบบนี้ต่อ ตามลำดับ: ต้นทุน → ของหายไปไหน → ราคาวัตถุดิบขึ้นลง → สต๊อก → ของเสีย → ยอดขาย → แดชบอร์ด → ซื้อของ
