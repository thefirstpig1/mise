ต้นทุนตามแผนก: เจ้าของร้านอยากรู้อะไร

ร้านที่มีครัวกับบาร์ ถามคำถามเดียวกับหน้าต้นทุน แต่แยกทีละแผนก: แผนกไหนทำเงิน ต้นทุนของแต่ละแผนกอยู่ในเป้าของแผนกนั้นไหม (บาร์กับครัวเป้าไม่เท่ากัน) ดีขึ้นหรือแย่ลง และอะไรในแผนกนั้นดันต้นทุนขึ้น

แยก P&LDepartmental P&L แยกยอดขายและต้นทุนของตามแผนก (Bar COGS = เหล้า เบียร์ ของตกแต่ง · Food COGS = วัตถุดิบ) เพื่อดูว่าบาร์กำไรแยกจากครัวเท่าไร
เป้าไม่เท่ากันอาหาร 28–35% · เบียร์ขวด ~25% · ซอฟต์ดริงก์ ~15% · บาร์รวม ต่ำกว่า 18% ดีมาก 24–28% เริ่มเสี่ยง — ใช้เป้าครัวกับบาร์ไม่ได้
อัตรากำไรต่างกันร้านที่บาร์แข็งแรงกำไรรวมสูงกว่าร้านอาหารล้วนชัดเจน — สัดส่วนยอดขายบาร์เป็นตัวเลขที่เจ้าของดู

คำถามที่ต้องตอบ

#คำถามตอบด้วยอะไรข้อมูลที่เรามี
1แผนกไหนทำเงินยอดขาย · กำไรขั้นต้น ฿ · ต้นทุน % · สัดส่วนยอดขาย ต่อแผนกมี (วิธีสูตรอาหาร)
2อยู่ในเป้าของแผนกไหมเป้าแผนก = เป้าต้นทุนต่อเมนูถ่วงตามยอดขาย (ใช้คอลัมน์ที่เพิ่งเพิ่ม) · เกินเป้ากี่บาทมี
3ดีขึ้นหรือแย่ลงกราฟเล็กต่อแผนก รายสัปดาห์/เดือน สเกลเดียวกัน · สัปดาห์ที่ตัดสต๊อกไม่ครบเป็นแท่งลาย (CO-COV)มี
4เมนูไหนดันต้นทุนแผนกเมนูในแผนกเรียงตามเงินที่เกินเป้ามี
5วัตถุดิบไหนกินเงินแผนกมากสุดต้นทุนวัตถุดิบในจาน × จานที่ขาย ต่อแผนกมี
6แผนกสั่งของมากกว่าที่ใช้ไหมของที่สั่งลงแผนก vs ของที่แผนกใช้จริง — สองตัวเลขที่ห้ามบวกกัน (F3)ใช้ไม่ได้ ใบรับของทุกใบลงแผนก Main
7หลังหักค่าแรงแผนก เหลือเท่าไรกำไรขั้นต้น − ค่าแรง/ค่าใช้จ่ายที่ลงแผนกยังไม่มี ค่าใช้จ่ายทุกบรรทัดเป็นส่วนกลาง
8ตัวเลขเชื่อได้แค่ไหนตัดสต๊อกครอบคลุมยอดขายแผนกกี่ % · เมนูไม่มีสูตรต่อแผนก · ของเสียและของไม่ตรงกับระบบไม่แบ่งแผนก (F7)มี

ร้านตัวอย่าง (สาขาอารีย์)

  • ก.ย.: ครัว ยอดขาย ฿501,599 ต้นทุน ฿191,296 = 38.1% · บาร์ ฿113,781 / ฿38,991 = 34.3% · บาร์ = 18% ของยอดขาย
  • ส.ค. → ก.ย. ทั้งสองแผนกต้นทุน % ลดลง (ครัว 41.3% → 38.1% · บาร์ 36.6% → 34.3%) แต่ ก.ย. ตัดสต๊อกครอบคลุมแค่ 85% ของยอดขาย จึงยังเชื่อว่าดีขึ้นไม่ได้
  • บาร์ 34% สูงกว่าเกณฑ์บาร์ทั่วไปมาก เพราะเบียร์/โค้กซื้อมาขายต่อ (ต้นทุน 73%/54%) — ต้องตั้งเป้าต่อเมนู ไม่งั้นบาร์ดูแย่กว่าความจริงหรือดีเกินจริง
  • 🔴 ใบรับของทั้งหมด (ก.ย. ฿390,645) ลงแผนก Main ซึ่งไม่มีเมนูอยู่ → “สั่ง vs ใช้” ต่อแผนกตอบไม่ได้ · ค่าใช้จ่าย ฿1,006,410 ทั้งหมดเป็นส่วนกลาง → ยังไม่มีกำไรหลังหักค่าแรงต่อแผนก
